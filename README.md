Palkon Auto: an original sunlit open-world crime game set in Solmar, a coastal city of seven districts. Courier Mara Venn uncovers a private security racket run by Bastion Civic and its broker, Silas Rook — eight linked missions, driving, police pursuit, garages, and a radio station, all in handwritten WebGL 2.

## Run it

```sh
python3 -m http.server --directory game
```

Then open http://localhost:8000 in a browser. `node main.ts` packages the game (game + screenshots + dossier.json) into `/output` for the make.fun grader.
